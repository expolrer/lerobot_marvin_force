# 机械臂调试UI使用说明

## 快速启动

```bash
cd /home/marvin/lerobot_marvin/src/lerobot/Marvin_sdk
python3 arm_ui.py
```

## 界面功能

### 1. 连接控制区（顶部）
- **机器人IP**: 输入机器人IP地址（默认 192.168.1.190）
- **连接**: 连接到机器人
- **断开**: 断开连接
- **状态指示**: 显示连接状态（绿色=已连接，红色=未连接）

### 2. 控制面板（左侧）

#### 选择机械臂
- 选择操作A臂或B臂

#### 错误控制
- **检查错误**: 查看当前错误码和伺服错误
- **清除错误**: 清除错误码

#### 状态控制
- **下使能 (IDLE)**: 关闭伺服，安全状态
- **位置模式**: 位置跟随模式
- **扭矩模式**: 扭矩控制模式

#### 阻抗控制
- **关节阻抗模式**: 进入关节空间阻抗控制（适合拖动）
- **笛卡尔阻抗模式**: 进入笛卡尔空间阻抗控制

#### 拖动控制
- **关节拖动**: 启用关节拖动（可手动拖动机械臂）
- **退出拖动**: 退出拖动模式

### 3. 关节位置显示区（右上）
- 实时显示7个关节的位置（度）
- ⚠ 标记接近限位的关节（>170度）
- 显示当前状态和阻抗类型
- **刷新位置**: 手动刷新
- **自动监控**: 勾选后每秒自动刷新

### 4. 日志输出区（底部）
- 显示所有操作的时间戳日志
- 显示错误和警告信息

### 5. 快捷按钮（底部）
- **B臂脱离限位**: 一键修复B臂限位问题（将第5关节从-176.14°移到0°）
- **回到Home位**: 移动选定的臂到全零位
- **清空日志**: 清空日志显示

## 典型使用流程

### 场景1：B臂限位修复
1. 点击"连接"
2. 选择"B臂"
3. 点击"B臂脱离限位"快捷按钮
4. 确认后观察B臂缓慢移动
5. 完成后可进入阻抗/拖动模式

### 场景2：进入拖动模式
1. 点击"连接"
2. 选择机械臂（A或B）
3. 点击"检查错误"（如有错误则点"清除错误"）
4. 点击"关节阻抗模式"
5. 点击"关节拖动"
6. 勾选"自动监控"查看实时位置
7. 现在可以手动拖动机械臂

### 场景3：回到安全位置
1. 选择机械臂
2. 点击"回到Home位"
3. 等待移动完成
4. 点击"下使能 (IDLE)"

## 注意事项

⚠️ **安全提示**
- 操作前确保机械臂周围无障碍物
- 进入拖动模式前确保机械臂不在限位位置
- 观察机械臂运动，如有异常立即按急停按钮
- 使用完毕后记得"下使能"

⚠️ **限位警告**
- 关节位置 > 170° 或 < -170° 会显示警告
- B臂第5关节在 -176.14° 时使用"B臂脱离限位"按钮

## 故障排除

**问题**: 连接失败
- 检查网线连接
- 确认IP地址正确
- 检查是否有其他程序占用连接

**问题**: 无法进入阻抗模式
- 先检查并清除错误
- 确保不在限位位置
- 如果状态码显示100，等待几秒后重试

**问题**: 关节接近限位
- 使用"B臂脱离限位"快捷按钮
- 或手动使用位置模式慢速移动

## 技术细节

- **GUI框架**: Tkinter
- **线程**: 自动监控使用独立线程
- **更新频率**: 1秒/次
- **默认阻抗参数**:
  - 关节阻抗: K=[2,2,2,1,1,1,1], D=[0.5,0.5,0.5,0.3,0.3,0.3,0.3]
  - 笛卡尔阻抗: K=[2000,2000,2000,40,40,40,20], D=[0.1,0.1,0.1,0.3,0.3,0.3,1]
